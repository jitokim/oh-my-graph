### Added

- **The web live view shows a paused gate's description above its approve/reject buttons.** It is the line the pause printed, rendered once when the gate paused and stored in `state.json` as the optional `gate.paused_gate_description` field, written with `paused_at`, with no schema bump. `/api/graph` copies it unchanged into a new `paused_gate` object (`id`, `description`); serve renders and sanitises nothing, and the page sets it via `textContent` only. The single-run view and the dashboard's run pages both show it. A decision made from the page records that same string, byte for byte, as the decided gate's `gate_description`, and `resume` now reads the stored copy too, rendering again only for a snapshot written before this field. CLI output is unchanged, and a gate without a description renders and records exactly as before. ([#348](https://github.com/jitokim/oh-my-graph/issues/348))
