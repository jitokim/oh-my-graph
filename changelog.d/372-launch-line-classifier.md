### Fixed

- **The Claude `auto` launch paragraph no longer calls a declared scope enforced.** It claimed that, because planned nodes run isolated, a declared scope like `Bash(git *)` holds as an enforced boundary, which has not been true since planned nodes moved to `--permission-mode auto` (ADR 0034): a call matching none of a node's allow rules is put to the CLI's own classifier, which approves or denies it, rather than being denied outright. The paragraph now says that none of your standing permission grants apply, that a call matching the node's allowed-tool rules runs, and that under the default permission mode one outside them goes to that classifier. It still says your CLAUDE.md, hooks and MCP servers are unavailable and points to SECURITY.md. The skill-activation block of the same launch screen, which restated the ceiling with the same retired scope claim, is corrected the same way: it now says that a call matching the node's allowed-tool rules runs and that one outside them goes to the CLI's classifier, and still says the ceiling is unchanged and that the only change activation makes is the `Skill` tool. `docs/EXAMPLES.md`'s copy of the launch output matches the new text, and its prose on skill activation is corrected the same way. The Codex runtime prints its own sandbox disclosure instead and is unchanged. ([#372](https://github.com/jitokim/oh-my-graph/issues/372))
