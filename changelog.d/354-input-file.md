### Added

- **`run` and `auto` can bind a graph's inputs from a file with `--input-file <path>`.** The file is a flat YAML or JSON map of input names to values, and each value is bound verbatim as written (`1.10` stays `1.10`, `yes` stays `yes`), as `--input name=value` would bind it. A nested value, a list, a null, a top level that is not a map, more than one YAML document and a key that appears twice in the same file (JSON included) are refused while the flags are parsed, naming the path, before any planner call, node or run directory. The flag is repeatable: a later file overrides an earlier one, and `--input` overrides every file wherever it sits on the command line. Each key set by more than one source gets one line on stderr naming the key and its sources, never the value. The merged values are checked exactly as `--input` values are and land in `state.json`'s existing inputs, with no schema change; `resume` reads them from there and never re-reads the file. ([#354](https://github.com/jitokim/oh-my-graph/issues/354))
