### Added

- **`run` and `auto` warn about a bound input key the graph does not declare.** Each key set by `--input` or `--input-file` that the graph's `inputs:` list does not name gets one warning line naming the key and its winning source (`--input`, or the file that set it last), never the value, with a `did you mean "<name>"?` tail when a declared name is a near miss (Levenshtein distance within 2 for a key of 4 or more runes, within 1 for 3 runes, never for shorter keys). A graph with no `inputs:` declares nothing, so every bound key warns, as `lint` already reads it. It is a warning, not a refusal: the key stays bound and the exit status is unchanged. `run` prints it at load, `--dry-run` included; `auto` prints it on the plan screen, judged against the planned graph and `--plan-only` included, once per key across a goal loop. `state.json` and the run feed (`events.jsonl`) are unchanged. ([#356](https://github.com/jitokim/oh-my-graph/issues/356))
