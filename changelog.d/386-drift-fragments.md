### Added

- **A shipped graph holds a change to its design document: `graphs/drift-review.yaml`, built from two new fragments, `drift-check` and `drift-nego`, and a new script, `scripts/drift-baseline.sh`.** The change is judged against a requirements file: one requirement per line, `ID | measure | source | check | text`, with `#` comments and blank lines ignored, and `measure` either `invariant` or `llm`. An empty source or check, an unknown measure or a duplicate ID is an error. `drift-check` is two nodes and runs invariants first. `baseline` runs no model: the engine runs the bound `baseline` command (the shipped script checks the lock, then the format, then every `invariant` entry's shell check) as the node's `verify:`, so a failure stops the run before any model judges drift. Then `check`, read-only under `plan`, diffs `base..head` against the design, judges only the `llm` entries, and answers `NO_DRIFT`, or `DRIFT:` with a JSON list naming, for each gap, the requirement it violates (`unlisted` when none does) and the commit behind it. It never sees the authors' reasons, so it cannot explain the drift away. The lock pins the design and the requirements file by sha256 and is owned by a person: the script only verifies it with `sha256sum -c` and never writes it, and the owner creates or updates it with `sha256sum <design> <requirements-file> > <lock-file>`. `drift-nego` is three nodes. `interview` speaks for each commit's author, `rule` gives every item fix-code, amend-design or accept-deviation and holds no write tool, and `fix` applies the fix-code items only, commits them with the oh-my-graph trailer, and is gated on an engine-run `verify:`. Each node is a fresh session handing on an artifact, so a run costs about five sessions. An `AMEND_DESIGN:` ruling fails `rule`'s check and halts the run before `fix`, because a gate cannot be conditional today. `check` and `interview` retry once on a result mismatch, since a misplaced token is a formatting slip, and `rule` never does, because its `AMEND_DESIGN:` failure is the stop for a human. The `nego` nodes still run after a `NO_DRIFT` check and answer at once. `head` is a required input (pass `HEAD`), and so are the new `requirements` and `baseline`. The interview is a fresh session reading the author's commits; resuming the author's own session is still open. ([#386](https://github.com/jitokim/oh-my-graph/issues/386))
