### Added

- **A shipped graph holds a change to its design document: `graphs/drift-review.yaml`, built from two new fragments, `drift-check` and `drift-nego`.** `drift-check` is one read-only node under `plan`. It diffs `base..head` against the design and answers `NO_DRIFT`, or `DRIFT:` with a JSON list that names the commit behind each gap. It never sees the authors' reasons, so it cannot explain the drift away. `drift-nego` is three nodes. `interview` speaks for each commit's author, `rule` gives every item fix-code, amend-design or accept-deviation and holds no write tool, and `fix` applies the fix-code items only, commits them with the oh-my-graph trailer, and is gated on an engine-run `verify:`. Each node is a fresh session handing on an artifact, so a run costs about four sessions. An `AMEND_DESIGN:` ruling fails `rule`'s check and halts the run before `fix`, because a gate cannot be conditional today. The `nego` nodes still run after a `NO_DRIFT` check and answer at once. `head` is a required input (pass `HEAD`). The interview is a fresh session reading the author's commits; resuming the author's own session is still open. ([#386](https://github.com/jitokim/oh-my-graph/issues/386))
